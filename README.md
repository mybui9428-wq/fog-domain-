# Fog Smoke Control (Minecraft 26.2 NeoForge)

Standalone mod. It does not include Mob War items, weapons, armor, entities, or systems.

Controller: `tubi2531` (case-insensitive).

Commands:
- `/fogsmoke help`
- `/fogsmoke cloud` or `/fogsmoke cloud <4-20>`
- `/fogsmoke move`
- `/fogsmoke expand`
- `/fogsmoke shrink`
- `/fogsmoke pull`
- `/fogsmoke bind`
- `/fogsmoke dash`
- `/fogsmoke hide`
- `/fogsmoke clear`
- `/fogsmoke status`

Cloud effects use server-side particles and entity effects. This does not create solid blocks or control smoke from other mods.

Build with Java 25: `./gradlew build`. Output: `build/libs/fogsmoke-1.0.0.jar`.
